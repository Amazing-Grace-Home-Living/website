What happens to my credential?
The wizard opens the official provider page, where you sign in and create your own credential. Paste it only into the hidden HOST terminal prompt. The encrypted vault is stored at ~/.grace-remote/vault.json, outside the repository. The companion unlocks only integrations you name at launch. Revoke or rotate keys in the provider dashboard. No provider secret is stored in extension storage, sent in chat, or exported into Git.
Cloud requests use the selected provider’s billing and data policies. There is no automatic fallback. Local inference still uses hardware and electricity. Google/GitHub browser sign-in does not grant API billing access to other services.


Provider chat has no tools. Codex tasks use host permissions; review approvals in the full console.
PowerShell execution is not enabled by this companion build. Use the host terminal for credential setup; secrets must never be entered here.
