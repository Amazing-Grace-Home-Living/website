02 / RUN

Travel mode: add --session-days 30 --remember-token to the command below. Save the token in your password manager. It survives restarts under the same Windows account. Browser locking does not revoke it.

The work happens on your host

Sign in to Codex on the host, configure GitHub and your deployment tools there, then launch from this package:

node bridge.mjs --cwd /path/to/repo

In Android Termux, connect to that computer:

pkg install openssh
ssh -N -L 8787:127.0.0.1:8787 USER@HOST

USER@HOST must be your configured, SSH-accessible computer. The companion binds to loopback, not the public internet.

03 / KNOW THE LIMITS

Control comes from permissions

The bridge uses Codex app-server. It can start and resume supported local threads, stream task events, show diffs, and answer command/file approvals.

Browser automation needs a browser tool configured on your host. GitHub pushes, merges and deployments need host credentials and the relevant tools. This app does not bypass denied permissions.

This is a personal companion, not a hosted service using customers’ ChatGPT subscriptions. Read the included README before distributing.

HOST VAULT / PERSONAL MODE
Store secrets outside your repository
On the host, run these commands from the companion folder. Tokens and passphrases are entered in hidden terminal prompts, never command arguments.
node vault.mjs set github
node vault.mjs list
node bridge.mjs --cwd /path/to/repo --integrations github

Rotate: node vault.mjs set github
Remove local copy: node vault.mjs remove github
Vault uses AES-256-GCM with a scrypt-derived passphrase key. Keep a strong unique passphrase. Unlock it on host startup. Removing a local token does not revoke it at GitHub/Vercel/OpenAI; revoke there too. Restart the companion after rotation/removal. Integrations explicitly enabled at startup are available to the Codex child process.
The session token is separate: browser-memory only, rotates on request, uses the lifetime configured on your host. Host vault tokens are never returned to the UI. This is not a managed or audited enterprise secret manager.
