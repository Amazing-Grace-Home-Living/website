PRIVACY

Clear by design.

This site is primarily static. The arcade and learning experiences store progress locally in your browser. The LM Studio setup stores endpoint and model preferences locally; it does not store API keys. External application and ministry links open their own sites, which have their own privacy policies.

Visitor analytics

We use Vercel Web Analytics for aggregate page views and referrals without analytics cookies. Query strings and fragments are removed before page views are sent. We do not send application details, notes, or quiz answers as analytics events.
