START ON YOUR WINDOWS COMPUTER

One companion. Your workspace.

  1. Download and extract the companion. Open PowerShell in the extracted folder containing bridge.mjs.
  2. Run the command below, replacing the repository path with your own. On later starts, the same saved token is reused.
  3. Open the printed local URL and enter the companion token only there. For a phone, connect your SSH tunnel first.
node .\bridge.mjs --cwd "C:\path\to\your\repository" --session-days 365 --remember-token --terminal

For authenticated LM Studio, add --lmstudio-token and enter the model token at its hidden host prompt. The model token and companion token are separate.

Install the sidebar extension
  1. Download and extract the sidebar ZIP.
  2. In Chrome or Brave, open the browser’s Extensions page. Enable Developer mode and select Load unpacked.
  3. Select the extracted folder containing manifest.json.
  4. Copy the extension’s ID. Restart your companion adding --extension-id YOUR_EXTENSION_ID.
  5. Click the extension toolbar icon and enter the companion token in the sidebar. Choose LM Studio, Ollama or Codex.

This is a personal unpacked extension, not a store installation. Actual Windows execution and your browser’s sidebar support need verification on your computer.

CHOOSE AN EXECUTION ENVIRONMENT

A command runner and an interactive shell do different jobs.

OptionWhat worksWhere it runs
Nexus PowerShell command runnerIndividual noninteractive commands and bounded output. No password prompts, interactive Codex CLI, persistent variables or administrator elevation.Your Windows host, through the companion.
Termux + SSHInteractive PowerShell or Bash, Codex CLI, installed cloud tools and login prompts under your remote account’s permissions.The Windows/Linux computer you connect to.

The public Nexus website does not provision a hosted execution machine, run arbitrary shell commands for visitors, or inherit their cloud accounts. A full interactive terminal embedded in Nexus is not implemented in this release.

INTERACTIVE / ANDROID TO YOUR HOST

Use Codex CLI, Bash, PowerShell or cloud tools

Termux provides your Android terminal. After SSH and your private network/VPN access are configured, open the shell you need. Replace the example username and host address with your real connection details.

Windows · interactive PowerShell from Termux

pkg install openssh
ssh -t WINDOWS_USER@PRIVATE_HOST powershell.exe -NoLogo

Once connected, run Codex in your repository if it is installed and signed in on that Windows account:

Set-Location "C:\path\to\your\repository"
codex

For cloud commands, install and authenticate the relevant CLI on that same host using its official login flow. A Nexus companion token does not sign you in to cloud providers.

Linux · interactive Bash from Termux

ssh -t LINUX_USER@LINUX_PRIVATE_HOST bash -l

Then run the installed tools you need inside that Linux environment:

cd /path/to/your/repository
codex

Windows WSL Bash is another option if WSL is installed and configured for the SSH account; it is not assumed to exist. Installers and administrator commands remain subject to the host account’s permissions. Do not enter passwords or model/provider tokens into public chat.

ANDROID / AWAY FROM HOME

Remote Login

Your PC must be powered on with the companion and working SSH server running. A home Wi-Fi address such as 192.168.x.x will not normally work from another house. Use the PC’s reachable private VPN address or private hostname from a VPN already configured on both devices.

  1. On your PC, start the companion from the folder containing bridge.mjs with --terminal if you want PowerShell commands. Keep it running.
  2. In Android Termux, install SSH and open the tunnel below. Replace WINDOWS_USER and PC_PRIVATE_VPN_IP with your actual Windows SSH username and reachable PC VPN address.
pkg install openssh
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 8787:127.0.0.1:8787 WINDOWS_USER@PC_PRIVATE_VPN_IP

Leave Termux connected. A successful ssh -N session may stay quiet. Open http://127.0.0.1:8787 in Chrome on this same phone and enter the companion token printed by the PC. The bridge can stay bound to the PC’s 127.0.0.1 address.

If it fails: SSH connection refused means check the PC SSH service and reachability. A channel-open connection-refused message means check the PC companion on port 8787. If the SSH server or VPN was never working before you left, this webpage cannot start it remotely; you need another existing remote-access method or someone at the PC. A token alone cannot establish the network connection.

Android: connection refused at 127.0.0.1:8787? That address is your phone. Start the companion on the PC, then keep the Termux SSH tunnel below connected before opening the local console. Keep the bridge bound to 127.0.0.1 on the PC; SSH forwards to that address. Binding to 0.0.0.0 is not required for a tunnel. If SSH reports connection refused on port 22, fix the PC SSH service first. If it reports channel open failed / connection refused, check that the companion is running on port 8787.

FOLLOW IN ORDER / WINDOWS → ANDROID

Connect your Android phone

Commands are labeled by device. Keep your existing companion PowerShell window running; use a second window for Windows checks.

1. Windows · check the SSH service

Get-Service sshd

Running: continue to step 3. Stopped: use step 2. Service not found: install OpenSSH Server using Microsoft’s Windows OpenSSH instructions, then return here.

2. Windows · if SSH is stopped

Open PowerShell as Administrator under your Windows account. These commands start SSH and enable startup after reboot:

Start-Service sshd
Set-Service -Name sshd -StartupType Automatic
Get-Service sshd

Continue when the status shows Running. This starts the SSH service; it does not configure an SSH login, keys or a private VPN for you.

SSH still will not start · collect the exact error

Use a second PowerShell window opened with Run as administrator. First verify elevation:

([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)

Continue when it returns True. Check the installed Windows OpenSSH configuration:

& "$env:WINDIR\System32\OpenSSH\sshd.exe" -t

No output usually means the configuration syntax check passed. If this executable is not found, inspect your actual OpenSSH installation rather than changing paths blindly. Read recent diagnostic events:

Get-WinEvent -LogName "OpenSSH/Operational" -MaxEvents 5 |
    Select-Object TimeCreated, Id, Message |
    Format-List

If that event log is unavailable, report that error too. These checks do not fix the service automatically. Resolve the reported cause before retrying Start-Service; do not reinstall or change network/firewall settings without evidence.

3. Windows · identify your SSH login

whoami
$env:USERNAME

Use the Windows account configured for SSH. For PRIVATE_HOST use the PC’s reachable private VPN address when away from home, or its LAN address when both devices are on the same network. The public website address and 127.0.0.1 are not the remote PC address. Verify the Windows SSH host fingerprint through a trusted channel before the first connection.

4. Android · open Termux

Install the SSH client in Termux, then run the tunnel command. Replace WINDOWS_USER and PRIVATE_HOST with your actual connection details. An established SSH login/key and network access are prerequisites.

pkg install openssh
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 8787:127.0.0.1:8787 WINDOWS_USER@PRIVATE_HOST

Build your tunnel command

This form only formats text on this page. It does not connect, save credentials or send these fields to a server.

Enter your SSH username and private host above to build the command.

5. Android · open Chrome or Brave

Keep Termux open and the tunnel running. Open http://127.0.0.1:8787/#assistant on your phone. Enter the companion token printed by your Windows companion—not the GitHub token, model token or vault passphrase. Select Codex, LM Studio or Ollama.

The SSH tunnel command normally stays quiet and does not return to the prompt while connected. If Android suspends Termux, reconnect. Both your PC and phone need their private network/VPN connection active when using a VPN address.

Optional · PowerShell directly in Termux

Open a second Termux session while leaving the tunnel running:

ssh -t WINDOWS_USER@PRIVATE_HOST powershell.exe -NoLogo

Do not expose port 8787 to the public internet. Keep host services behind your configured private SSH/VPN access.

USE THE RIGHT TOKEN IN THE RIGHT PLACE

Add or replace tokens

TokenWhere to enter itWhat it does
Companion tokenLocal console or installed sidebar’s companion fieldUnlocks your running companion; it does not sign in to an AI provider.
LM Studio model tokenHidden PowerShell prompt with --lmstudio-tokenAuthenticates the companion to your LM Studio server.
GitHub / Vercel tokenHidden vault prompt using the commands belowSupplies credentials to enabled tools on the host.
Optional OpenAI API keyHidden vault prompt: node .\vault.mjs set openaiFor separately configured host API tools. Does not switch this site’s hosted account or grant ChatGPT access.

GitHub and Vercel · run on Windows

Run these one at a time from the extracted companion folder. The vault asks for its passphrase, then each provider token through hidden prompts. Never put token values in these commands or chat.

node .\vault.mjs set github
node .\vault.mjs set vercel
node .\vault.mjs list

Enable only the integrations you have stored:

node .\bridge.mjs --cwd "C:\path\to\your\repository" --integrations github,vercel --session-days 365 --remember-token --terminal

stored: true means encrypted storage exists. configured: false in the standalone list is expected until startup loads that integration; neither value proves provider permissions. “No stored token” means run vault.mjs set for that provider first. Vault unlocks are interactive, so this launch command is not suitable for an unattended startup task.

LM Studio · use the model token

In LM Studio, load a chat model and start the Developer server. If Require Authentication is enabled, create a token under Developer → Server Settings → Manage Tokens. Then run on Windows:

node .\bridge.mjs --cwd "C:\path\to\your\repository" --session-days 365 --remember-token --terminal --lmstudio-token

Paste the model token only at the hidden LM Studio API token prompt. In the browser choose LM Studio, enter the separate companion token and select Connect / refresh models, then choose your model. See LM Studio’s token instructions.

Rotate or remove an integration token

Replace the saved token:

node .\vault.mjs set github

Or remove its local copy:

node .\vault.mjs remove github

Choose one command: set replaces the saved GitHub token; remove deletes the local copy. Stop and restart the companion afterward. Revoke removed or exposed credentials at the provider too.

Replace a companion token

Stop the companion with Ctrl+C, then issue a replacement:

node .\bridge.mjs --cwd "C:\path\to\your\repository" --session-days 365 --remember-token --reset-token --terminal

Use 90, 120 or 365 days. Save the new token privately and omit --reset-token on normal restarts. A saved token retains its original expiry; changing the days argument does not extend an existing token.

Additional providers and custom token slots

Only declared IDs can be saved. Register a custom host tool’s metadata in integrations.json, then store its credential with node .\vault.mjs set PROVIDER_ID. For example:

[
  {
    "id": "custom-tool",
    "name": "My custom host tool",
    "env": "CUSTOM_TOOL_API_KEY",
    "description": "Credentials for my separately installed host tool."
  }
]

Merge the entry into the existing array; do not overwrite other entries. Then use --integrations custom-tool on startup. This only supplies a token to a configured host tool; it does not create an API integration, install software or add a new chat provider.

COMMAND CONSOLE / YOUR WINDOWS HOST

Run noninteractive PowerShell commands

The terminal is included in the companion. Download the latest package, extract it and start it with --terminal. You can then run commands from the local browser console or an Android browser through your SSH tunnel.

Open connected PowerShell terminal ↗View terminal & setup on this website →

Enter your companion token, select Connect / refresh, then enter a command and choose Run command. Example:

Get-Service sshd

Each command starts a fresh PowerShell process in the configured repository. Output appears in the console. Interactive password/token prompts and administrator elevation are not supported there; use host PowerShell for those. The public HTTPS website cannot directly access your PC’s private HTTP terminal, so execution opens at the local companion URL. AI chat does not execute commands in this terminal automatically.
