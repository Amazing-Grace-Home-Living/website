# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Actively supported |
| < 1.0   | ❌ No longer supported |

## Reporting Vulnerabilities

If you discover a security vulnerability, please report it to **info@amazinggracehl.org**. We aim to acknowledge receipt within **48–72 hours** and will work with you to resolve the issue promptly.

## Policy

- We will not publicly disclose any vulnerability details until a fix is available.
- All reports will be handled confidentially.
- We encourage responsible disclosure and will credit the reporter where appropriate.
