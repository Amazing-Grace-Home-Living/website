YOUR LEARNING PASSPORT

Keep your checkpoints with you.

Download a JSON backup of saved learning progress and restore it in another browser. This includes the learning campaign, RPG quests and choices, Code Matrix board, VIM/Bash checkpoint and review history, PowerShell Academy profile, legacy Matrix Academy passport, Signal Bonus balance and earned rewards, and Seven Stars locations.

It includes your chosen player name if saved. It excludes unrelated browser storage, credentials, unsaved combat frames, gameplay currency, and tower-upgrade loadouts. Signal Bonus balances merge by keeping the higher saved balance, so restoring the same file cannot duplicate credits. No file is uploaded to a server.

Review the merge before applying

    Merge keeps earned milestones, the furthest Code Matrix level, your existing story choices, and the higher Signal Bonus balance. Current VIM/Bash wave checkpoints take precedence. Close other game tabs before restoring, or reload them afterward; live combat frames are not in this backup.

    Your pace. Your progress.

    Lessons and puzzles remain replayable. Losing a mission keeps your earned progress. Completion XP and badges are awarded once; they do not buy quiz passes or unlocks.

    Progress lives in this browser on this site. It does not sync to an account. Browser data can be edited, so these results are for personal practice, not graded certification.
